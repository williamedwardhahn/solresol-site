A research note · Solresol

A language you can see, hear, and grow

A nearly 200-year-old idea — seven syllables that are also seven notes and seven colours — rebuilt as a shared meaning space: one structured code an LLM can reason in, a person can perceive, and agents can invent for themselves. This is the honest field report — what won, what lost, and what the evidence says it's actually for.

IThe bet

Natural language ties meaning to form arbitrarily — cat, cats, and feline are unrelated symbols a model must memorise. The bet here is the opposite: make the form encode the meaning. Each concept becomes a short run of seven ring-ordered symbols, built so that similar meanings get similar codes. The seven aren't arbitrary either — the visible spectrum is almost exactly one optical octave, so a note's pitch-ratio maps to a hue by physics: do=red … si=violet.

If it works, one code renders as sound, colour, or touch (for people), factors cleanly (for machines), and stays robust when a symbol slips. If it fails, it fails honestly — and it did, in one place.

IIWhat the evidence says

Every number below is from a run that's in the repo, most of it trained from scratch on a laptop in seconds.

questionstructured codethe alternative
Generalise to unseen concepts? 1.000.00 (arbitrary / hash)
Survive a fumbled symbol? 100%2% (87% catastrophic)
Can it grow itself — no corpus, self-play, then generalise? 0.920.17 (chance)
Beat a hash embedding at topic classification? 0.6230.748 (BERT-Hash)

Learnability & robustness: a tiny transformer, structured vs arbitrary codes. Self-play: a discrimination game with a population of agents, zero-shot on held-out meanings. Classification: 20-Newsgroups, structured 448 params vs hash 262K vs a full table 1.5M.

Three wins and one clean loss. The wins say structure buys compositional generalisation, graceful degradation, and a language that can invent itself. The loss says something just as useful: at extreme compression a seven-symbol code throws away the word-identity that topic classification rewards. It is not a drop-in better tokenizer — and pretending otherwise would waste everyone's time.

IIIThe frontier, drawn by data

Where structure wins

  • Compositional generalisation — decodes concepts it never saw; the arbitrary and hashed codes cannot.
  • Graceful degradation — a slip lands on a neighbour meaning, not noise. Robust I/O over noisy channels.
  • Self-play emergent communication — agents grow a shared, generalising code with no data at all.
  • Interpretability & algebra — readable coordinates; king − man + woman → father as an edit on the code.
  • Parameter collapse — 448 params where a table needs 1.5M, when identity isn't the point.

Where it loses

  • Identity-heavy classification — topic labels reward word-specific features that extreme compression destroys. Hash and full tables win.
  • Frontier-scale throughput — 4× longer sequences, ~16× attention. BPE wins on cost at scale; entropy is conserved.
  • Context & polysemy — a static code freezes meaning a big model would rather build from context.

So the honest product is not "better embeddings." It is a self-growing, compositional, interpretable, robust meaning-code — best exactly where a learner is bounded and the channel is noisy: on-device models, agent-to-agent messaging, accessibility, and auditable I/O. The same niche, whether the bounded learner is a tiny model or a child.

IVTurning the defects into the spec

Grace Hopper kept a nanosecond of wire on her desk to make a limit teach something. Read the "weaknesses" that way and they name the mission:

A code with no out-of-vocabulary fallback…
…invents a word for an unseen concept in the right neighbourhood. Coinage, not failure.
A meaning that's fixed, not context-built…
…is unambiguous and verifiable — the anti-hallucination property a reasoning substrate wants.
Emergent codes that are private and idiosyncratic…
…are exactly what a personal, self-grown language needs — the child's, or the agent's, own.
Only seven symbols…
…is the most a bounded perceiver reliably tells apart, and the only radix that renders as note, colour, and touch at once.

VWhere it goes

One shared meaning space; an LLM as the reasoner that reads and writes it; and a renderer for each party — sound and colour for people, the code itself for machines, a transposed signal for other species. The self-play result is the engine: a language that generates its own training data and improves without a ceiling. The classification loss drew the wall we won't run at. Both were worth knowing.

Build the language that a small mind — silicon or human — can learn, grow, and never be badly misheard in.
