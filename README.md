# solresol-site

The built site for **[solresol.xyz](https://solresol.xyz)** — nothing else.

This repo is public only so GitHub Pages can serve it. It holds no source
of record: every file here is generated by `npm run build` in the private
**solresol** repo and pushed with `python3 tools/build/publish-site.py`.

Don't edit anything here — the next publish overwrites it. Change `src/`
in the source repo instead.

| path | what it is |
|---|---|
| `index.html` + `src/` | the app: a word built from notes, shown in every voice at once |
| `solresol.html` | the whole app inlined into one file that opens on double-click |
| `toy.html` | seven keys, no meaning, nothing to fail |
| `theory.html`, `physics.html` | the project as one equation, and as physics |
| `maya.html` | the AAC board the whole thing is for |
| `demos_interlingua.html`, `solresol_capstone.html` | the learned interlingua, and the capstone |
| `CNAME` | binds the custom domain |
